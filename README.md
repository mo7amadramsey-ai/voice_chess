# شطرنج صوتي — الإصدار 0.1

## التحميل
آخر نسخة: https://github.com/mo7amadramsey-ai/voice_chess/releases/latest/download/voice-chess.apk

## محلي بالكامل
- الصوت: مقاطع عصبية مدمجة داخل الـ APK (تُصنع وقت البناء) — لا إنترنت وقت التشغيل.
- المحرك: Stockfish على الجهاز.
- الاستماع: التعرّف **على الجهاز** (ثبّت حزمة العربية/الإنجليزية دون إنترنت من إعدادات لغة Google). التطبيق لا يملك إذن إنترنت أصلًا.

## بناء الـ APK (بدون تثبيت أي شيء على جهازك)
1. أنشئ مستودعًا خاصًا جديدًا على GitHub وارفع محتويات هذا المجلد إليه (بما فيها المجلد المخفي `.github`).
2. تبويب **Actions** ← **Build APK** ← **Run workflow**.
3. بعد دقائق: حمّل `voice-chess-apk` من قسم Artifacts ثم ثبّت `app-release.apk`.

الخطوة الأولى في الـ workflow تولّد "صوت التطبيق" (44 مقطعًا × لغتين) بصوت عصبي طبيعي وتضمّه داخل الـ APK.
لتغيير الصوت: عدّل المتغيرات `VOICE_AR` / `VOICE_EN` في `tool/make_voice_pack.py` (مثال أنثوي: `ar-JO-SanaNeural`).

## اختبار "عقل الأوامر الصوتية" محليًا
`dart tool/parser_check.dart`  (38 حالة: عربي/إنجليزي/مختلط/ضوضاء)

## أوامر صوتية مدعومة
نقلة: `حصان اف 3` · `knight f3` · `جندي اي 4` · `e4` · `بيشوب c4` · `حصان d2 الى f3` · `تبييت قصير/طويل` · `b8 وزير`
تحكم: `نيو جيم [وايت|بلاك]` · `مستوى 1200` أو `level 5` · `تراجع` · `تلميح` · `كرر` · `استسلم` · `اقلب` · `توقف`
